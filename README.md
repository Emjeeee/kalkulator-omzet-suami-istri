# Kalkulator Penggabungan Omzet Suami Istri

Alat hitung gratis untuk memeriksa apakah omzet gabungan suami, istri, dan
seluruh perseroan perorangan masih di bawah batas Rp4,8 miliar menurut
PP 20 Tahun 2026.

Satu berkas HTML, tanpa server, tanpa cookie, tanpa analitik. Angka yang diisi
tidak pernah meninggalkan perangkat pengguna.
